Throw GitHub

Send files and text to nearby devices.

Throw is for people on Android, Windows, and Linux who need to move files and text between devices directly. Transfers happen over WiFi Direct and Bluetooth, so they don't depend on an internet connection.

Download Throw →

Features

  • Transfers over WiFi Direct. Router not involved.
  • BLE handles discovery. Low power, always scanning.
  • Files move device to device. No server in the middle.
  • Clipboard sync built in. Copy here, paste there.
  • English and বাংলা from day one. Switch any time.
  • MIT licensed. Source on GitHub.

FAQ

Does Throw need internet?

Transfers run over WiFi Direct and Bluetooth. An internet connection is never involved.

Do both devices need to be on the same Wi-Fi network?

WiFi Direct forms its own direct link between the two devices. A router is never involved.

Do my files pass through a server?

Files move device to device. There is no server that ever sees them.

Which platforms are supported?

Android, Windows, and Linux today. iOS and macOS are not supported yet.

How far apart can the devices be?

Within Bluetooth and WiFi range — practically, the same room. Throw is built for nearby, not remote.

How much does it cost?

MIT licensed and free. The source is on GitHub.
