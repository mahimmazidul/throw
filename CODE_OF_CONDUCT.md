# Code of Conduct

Contributor Covenant v2.1, summarized:

**Be respectful.** That is all.

In practice:

- Treat people with respect in issues, PRs, and discussions
- No harassment, personal attacks, or discriminatory language
- Assume good intent, and ask for clarification before escalating

Report unacceptable behavior by contacting the repository maintainer.
Maintainers will review and respond as time allows.

Full text: [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code-of-conduct.html)
